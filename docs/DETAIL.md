# 字符雷霆

把对话区变成一场纵版字符空战。右侧边缘的小球常驻在所有内容之上；点它，会话区被一层字符战场接住——正在显示的文字先被一片字符噪点从下往上扫散，随后星野亮起、我方战机从底部升起、敌机压下来。再点一次或按 `ESC`，战场整层移除，对话原样回来。

场景里没有图片、没有图标、没有绘制的图形：战机、敌机、子弹、弹幕、爆炸、星空、边框、血条、暂停与结束画面，全部是字符网格里刷新的字符。渲染跑在 canvas 上（60 帧，逻辑同帧率），所以子弹和弹幕是流动的，不是一顿一顿的。

## 使用

1. 装好插件并重启一次 DSH，窗口右侧出现一个青色小球（`▲`）。
2. 单击小球进入战斗；战斗中球变成 `×`，再点一次回到对话。
3. 小球可以按住拖到任意位置，位置会记住；在球上点右键回到默认位置。
4. 退出只移除游戏层。对话没有被卸载、没有被滚动、没有被改写：正在生成的回复在下面继续跑，回来接上。

## 操作

| 输入 | 动作 |
| --- | --- |
| `WASD` / 方向键 | 移动战机（主炮自动开火） |
| 鼠标在画面内移动 | 同样可以带飞机（要先真的挪一段距离才接管，避免刚进来就跳到鼠标处） |
| `X` | 炸弹：清空敌弹，重创全场，并给一段无敌 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |
| `ESC` | 退出，回到对话 |
| 结束画面按 `R` | 再来一局 |

## 系统

- **主炮五级**：单发 → 双发 → 三向 → 四向 → 五向加尾炮，每升一级火力肉眼可见。
- **僚机**：拾取 `W` 后左右各一架跟随射击，最多两架。
- **副武器**：`M` 跟踪导弹（自动转向最近的敌人），`A` 穿甲弹（高速贯穿，可打穿多个敌人）。
- **生存**：三条命、中心小判定点、`S` 护盾（最多两层）、`B` 炸弹 +1、`C` 能量水晶加分。
- **敌机**：侦察机 `v`、蛇形机 `s`、俯冲机 `@`、炮台 `W`（三向扇形弹）、激光机 `L`（先亮预警线再开火）、精英机 `X`（环形弹幕）。
- **BOSS**：每四波一个，两阶段；半血进入狂暴，弹幕换成螺旋加激光。血条画在状态行上。
- 最高分与悬浮球位置保存在浏览器本地存储里，换会话、刷新页面都不丢。

## 边界

- 游戏层只覆盖在会话区上，尺寸跟着会话区走；它不读取消息内容——开场只**读取**可见字符的位置来放粒子，原文一个字节都没改。
- 关闭即恢复。整个过程中对话内容、滚动位置、草稿、正在运行的回合都不受影响。
- 本局进度不落盘：退出或重开即结束，只保留最高分。
- 卸载插件后，本地存储里的两个键（`dsh.ascii-thunder.hi`、`dsh.ascii-thunder.ball`）会留在浏览器里，可手动清理。
